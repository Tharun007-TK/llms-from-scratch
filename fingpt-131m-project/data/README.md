This directory contains raw corpus data and processed/tokenized intermediates
generated by the data pipeline in `01_data-collection/` and `02_corpus-extraction/`.

These files are **not tracked by git** (see `.gitignore`). They are large binary
files that would bloat the repository and are reproducible from the pipeline scripts.

The final, cleaned, published dataset is available on Hugging Face:

    https://huggingface.co/datasets/Tharun007/gst-rulings-corpus

To regenerate the data locally:
1. Run `01_data-collection/01_main-chapter-code/fetch_gstcouncil_aar.py` to scrape PDFs into `raw/aar_rulings/`
2. Run `01_data-collection/01_main-chapter-code/fetch_indiacode_docs.py` to scrape India Code documents into `raw/bare_acts/`
3. Run `02_corpus-extraction/01_main-chapter-code/extract_corpus.py` to produce `processed/train.jsonl` and `processed/val.jsonl`
4. Run `03_dataset-publishing/01_main-chapter-code/build_hf_dataset.py` to produce the HF dataset in `03_dataset-publishing/01_main-chapter-code/hf_dataset/`
