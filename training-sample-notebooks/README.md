# Training Sample Notebooks

This folder contains beginner-friendly notebooks that explain core language model concepts step by step.

## Files in this folder

1. `episode-1-what-is-a-language-model.ipynb`
- Introduces what a language model is.
- Covers basic intuition for next-token prediction.

2. `episode-2-tokenization.ipynb`
- Explains tokenization and why raw text must be converted into tokens.
- Demonstrates how vocabulary and token IDs work.

3. `episode-3-embeddings.ipynb`
- Introduces embeddings and vector representations of tokens.
- Shows how embeddings capture semantic structure for model input.

4. `episode-4-self-attention.ipynb`
- Explains self-attention at a conceptual and practical level.
- Connects attention mechanics to transformer behavior.

## Suggested learning order

Use the notebooks in numeric order (Episode 1 to Episode 4). Each episode builds on concepts from the previous one.

## Requirements

- Python 3.10+
- Jupyter Notebook or JupyterLab
